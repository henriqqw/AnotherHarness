# 编辑代码

[English](edit-code.md) | 中文

工作区文件在右侧边栏中打开。源代码文件在代码编辑器中打开，选择**编辑**之前为只读。

## 打开并编辑文件

从文件面板或对话中的链接打开文件。选择**编辑**开始输入，然后选择**保存**或按 Ctrl/Cmd+S。圆点表示有未保存的更改；**放弃更改**会恢复为磁盘上的文件。Markdown、HTML、CSV 等有渲染视图的文件默认以渲染形式打开；从查看器菜单中选择**编辑器**即可编辑。查看器菜单还提供**代码**，即只读预览，可用于超过 1 MiB 编辑上限的文件。

编辑器使用 VS Code 的快捷键：Alt+单击和 Ctrl/Cmd+D 添加光标，Alt+上/下移动行，Ctrl/Cmd+/ 切换注释，Ctrl/Cmd+F 和 Ctrl/Cmd+H 搜索和替换，Ctrl+G 转到行。补全建议来自文件中的单词。状态栏显示光标位置，并可更改语言、缩进和行尾。

每个打开的文件是一个标签页。使用侧边栏的全屏控件获得完整的编辑区域，按 Ctrl/Cmd+Alt+S 保存所有已更改的文件。关闭有未保存更改的标签页时会先询问是否保存。

## 文件在磁盘上被更改时

如果在你有未保存更改时，代理或另一个浏览器更改了该文件，横幅会保留你的草稿，并提供**重新加载**（采用磁盘版本）、**比较**（并排查看两个版本）和**覆盖**（确认后用你的版本覆盖磁盘版本）。没有未保存更改时，编辑器会静默重新加载。你保存后，编辑同一文件的代理会被告知文件已更改，并先读取你的版本。

只有工作区内、不超过可编辑大小上限（默认 1 MiB）的 UTF-8 文本文件可以编辑。

## 管理文件

在文件面板中右键单击文件或文件夹，或使用其标题栏中的按钮，可以**新建文件**、**新建文件夹**、**重命名**（F2）、**删除**和**显示文件位置**（在系统文件管理器中选中该项目）。删除总会先询问并写明项目名称；删除文件夹会删除其中的所有内容。打开的标签页会跟随被重命名的文件。

在 git 仓库中，文件树会像 VS Code 一样标记已更改的文件：已修改的文件显示为黄色并带 **M**，新增和未跟踪的文件显示为绿色并带 **A** 或 **U**，冲突显示为红色并带 **C**，包含更改的文件夹会显示一个圆点。标题栏中的分支按钮会列出所有已更改的文件，包括已删除的文件。

## 代码导航

为该文件类型配置了语言服务器时，将鼠标悬停在符号上可查看其类型和文档，按 F12 或 Ctrl/Cmd+单击转到定义，按 Shift+F12 列出引用。没有语言服务器时，这些操作不起作用。

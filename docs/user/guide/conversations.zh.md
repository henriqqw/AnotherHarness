# 管理对话

[English](conversations.md) | 中文

每条消息和每个已完成的轮次下方都有操作按钮，侧栏中的每个对话都有一个菜单。编辑、回退和分支都不会改写原对话，而是创建一个新对话，因此之前的历史仍然可以查看。

## 复制消息

点击用户消息或助手回复下方的复制图标。用户消息复制其文本；助手回复复制其 Markdown。

## 从某一轮分支

在任意带有回复的已完成轮次末尾点击分支图标。新对话会打开，并包含截至该轮的历史。原对话保持不变，仍然可见。

## 回退到某一轮

在已完成轮次末尾点击回退图标。新对话会打开，并包含截至该轮的历史，原对话会被归档。如需找回原对话，在侧栏筛选中选择**全部对话（显示已归档）**并恢复它。

回退不会撤销 Agent（智能体）在该轮之后对文件所做的修改。

## 编辑已发送的消息

点击你的消息下方的编辑图标，修改文本，然后按 **Enter** 或点击**发送**。**Shift+Enter** 换行，**Escape** 取消。编辑后的消息会在一个新对话中继续，该对话包含这条消息之前的历史，原对话会被归档。编辑第一条消息会在同一工作区中开始一个新对话。

暂不支持编辑带附件的消息；请改为发送一条新消息。

## 删除对话

在侧栏中打开对话的菜单，选择**删除会话**。对话框会显示对话名称；确认后，其历史会从本机删除，且无法恢复。仍在运行或有后台工作的对话需要先停止。如只想隐藏对话而不丢失它，请改用归档。

删除对话不会影响从它分支出的对话，也会保留可能被其他对话共用的附件文件。

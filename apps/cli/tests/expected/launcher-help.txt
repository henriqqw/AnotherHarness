Usage: ah [--profile] <name> [options] [app-args...]
       ah plugin --profile <name> <pnpm-args...>

ah: boot an AnotherHarness profile — an ordered stack of plugin-bundle patch
layers under your own overrides.

Arguments:
  args                           arguments for the booted profile's app (see:
                                 ah --profile <name> --help)

Options:
  -V, --version                  output the version number
  --profile <name>               the profile under $AH_HOME/profiles to boot
  --from-default-profile <name>  initialize a new custom profile from a shipped
                                 profile template
  --patch <path>                 extra patch-list overlay applied after the
                                 profile layer (repeatable)
  --dump-config                  print the composed profile tree and exit
  --dump-config-schema           print JSON Schema for profile entries and
                                 patches without mounting
  --dump-default-config          print the profile tree without its user layer
                                 or --patch overlays and exit

Examples:
  ah web                                   boot the web profile (same as: ah --profile web)
  ah rescue --from-default-profile web
                                            create rescue from the shipped web template, then boot it
  ah headless "run the tests"              answer one task, print the result, and exit
  ah tui --patch ./extra.yml               boot a custom profile with one extra overlay
  ah tui --resume <session>                arguments after the launcher flags reach the app
  ah web --help                            the web app's own flags and help
  ah plugin --profile tui add <package>    install a plugin into the tui profile
